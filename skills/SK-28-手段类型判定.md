# SK-28 手段类型判定

## 何时用

S4。候选手段已列出，需要判定**每个手段对各个目标是收益还是损害**时。

**本技能只判类型，不算强度。** 强度走 SK-27。

## 输入 / 输出

- **输入**：某手段 ＋ 它影响到的目标集合。
- **输出**：该手段的**类型标记**（等终／多终／反终）＋ 它损害了哪些目标。

## 操作

### 一、判类型

| 类型 | 定义 | 对被服务目标的连接 |
|---|---|---|
| **等终**（equifinal） | 达成同一目标的**多个手段之一**（与同类手段并列） | **稀释**（集合越大越弱） |
| **多终**（multifinal） | **同时服务于多个目标** | **稀释**——且每个目标的连接都被稀释 |
| **单终**（unifinal） | **只达成一个目标** | **强联想**——效率低，但人们往往对追求它**高度内在动机** |
| **反终**（counterfinal） | **同时达成某些目标并损害另一些目标** | **反而被知觉为对所服务目标更工具性** |

### 二、记住三条反直觉的对称

1. **等终性的劣势恰是单终性的优势**：等终手段构成备份方案（提高目标承诺），代价是稀释联想；单终手段效率低，优势是**强联想与高内在动机**。
2. **多终「理应」占优，但人不总选它**——人们**常常偏好达成更少目标的手段**（过度理由效应；3 岁孩子已能推断「被说成能让你变强的东西不会好吃」）。
3. **反终性不是缺陷，是吸引力来源**：反终手段**常非最优**（最小化而非最大化目标达成），但**恰恰因为它们抑制了另一目标**，而可能显得对所促成的那个目标**更具工具性**。

### 三、使用「代价启发式」

**代价被视为有效性的证明**——如「没有付出就没有收获」。某加拿大药企把止咳糖浆宣传为「**难喝但有效**」，传达的正是**因为它损害了味道目标，所以它对去除咳嗽这个目标更具工具性**。

**经验支持**：产品被知觉为越反终性，其**被知觉到的有效性越强**（如「灼烧感漱口水」在杀菌上被评为更有效）；反终性导致**对手段更正向的态度**。

### 四、判反终手段「何时会被采用」

| 条件 | 效果 |
|---|---|
| **一般目标达成期望较低** | 反终性手段的吸引力**更明显**（抑郁或焦虑水平高、对达成可能性总体悲观的个体**表现出强烈偏好**；「治愈重病」比「治愈感冒」更让人偏好昂贵手段） |
| **动机失衡**（一个需要主导、其余需要显著性下降） | **解除对反终行为的抑制**；**极端人格正向预测反终行为频率** |
| **一个目标成为主导、其他被挤出** | 服务于主导目标（同时损害其他目标）的反终手段**特别有吸引力** |
| **多数人试图维持动机平衡** | **他们不去执行那些牺牲其部分需要的反终行为**——故**反终行为通常是罕见的**，与其被称为「极端」相一致 |

### 五、登记：什么会抑制反终手段

**对焦点目标与替代目标的「同时承诺」，会降低对反终性手段的偏好。**

## 边界与失效条件

- ⚠️ **「损害计为正向贡献」与 SK-29 存在计分空白**。P36-13b 的 `derivation_note` 已登记：这是本项目**唯一一条把「损害」计为正向贡献**的规则，而 P30 的规范贡献模型**未规定损害如何计分**。**同时使用 SK-28 与 SK-29 时，必须先说明损害项归谁计。**
- ⚠️ **判据是「知觉到的工具性」，不是「实际达成率」**。P36-13b 的经验支持测的是前者。**若本课题要预测人物相信什么，用它；若要预测实际做成什么，不能用它。**
- **反终行为通常是罕见的**（P36-15）。它需要**动机失衡**才能解除抑制。**不要把反终手段列为常规候选**——它要额外条件才被采用。
- **「罕见」不等于「不可能」**：动机失衡、极端人格、单一目标主导，任一出现即可解除抑制。**判定时要显式检查这三个条件。**
- **多终不总被偏好**（P36-05）：按效率预测会错。**过度理由效应**是稳定现象（3 岁即出现）。若人物偏好单终手段，**那是正常，不是缺陷**。
- **认知闭合需求是调节变量**（P36-07）：高认知闭合者**更可能**偏好反终手段。该变量若在输入里没给，**不要假定默认值**。
- **不要把「代价启发式」外推到非手段语境**。它说的是**手段的工具性知觉**，不是「受苦本身有价值」。

## 附：代价启发式的来源边界

P36-13b 的经验支持来自 Schumpe 等（2018）系列研究与 Bélanger 等（2015）。**它们测的是「知觉到的工具性」，不是「实际达成率」。** 原文中这两者**不是同一件事**。
