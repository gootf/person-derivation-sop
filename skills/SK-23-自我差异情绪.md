# SK-23 自我差异情绪

## 何时用

S4。**当情绪不由「事件对目标的意义」引起，而由「自我表征与标准之间的落差」引起时**。

与 SK-22 的分工：SK-22 管**事件型**情绪（12 个），本技能管**自我评价型**情绪。两者不可互相替代。

## 输入 / 输出

- **输入**：人物的三种自我状态表征 + 两种立场。
- **输出**：情绪类（而非具体情绪词）。

## 操作

### 一、取三种自我状态表征

| 表征 | 定义 |
|---|---|
| **实际自我**（actual self） | 你对自己当前拥有何种属性的表征 |
| **理想自我**（ideal self） | 你希望理想地拥有的属性表征 |
| **应该自我**（ought self） | 某人（你自己或他人）相信你**应当或必须**拥有的属性表征 |

### 二、取两种立场

| 立场 | 含义 |
|---|---|
| **你自己的个人立场** | 反映一组态度或价值的、可据以评判你的观点 |
| **某个重要他人的立场** | 如母亲、父亲、兄弟姐妹、配偶、最亲密的朋友 |

### 三、取四种差异（实际自我 对 指导物）

| 差异 | 指导物 |
|---|---|
| 1 | actual/own : **ideal**/own |
| 2 | actual/own : **ideal**/other |
| 3 | actual/own : **ought**/own |
| 4 | actual/own : **ought**/other |

### 四、按关系类型定「负面心理处境」类型

**两类关系分别对应两类负面心理处境**，再各对应一类情绪：

| 负面心理处境 | 内容 | 关联情绪类 |
|---|---|---|
| **(a) 积极结果的缺失**（实际的或预期的） | 认为自己**已经失去或永远无法得到**某个期望目标 | **沮丧类**（不满、失望、悲伤） |
| **(b) 负面结果的存在**（实际的或预期的） | 认为**可怕的事将要发生** | **激动类**（恐惧、威胁、坐立不安） |

**判据是差异关系的类型**（ideal 还是 ought、own 还是 other），**不是差异的大小**。

**注意链条有两级**：关系类型 → **负面心理处境类型** → 情绪类。**不要跳过中间那级直接从关系跳到情绪词。**

## 边界与失效条件

- ⚠️ **判据是差异的「类型」，不是「大小」**。材料明确「**不同类型的关系代表不同类别的情绪**」。系统自建一个「差异越大情绪越强」的连续量会脱离依据。
- **不要假定差异的来源是「未达内在一致性」**。P40-04 明写：「**自我差异的来源不被假定为只是未达内在一致性或『良好完形契合』。**」不要把它当成本 SOP 内部一致性检查的一个子情形。
- **两种立场必须分开**。仅区分「自我的不同域」不够——**同一域在不同立场下是不同表征**（你关于自己个人理想的信念 ≠ 你关于母亲希望你拥有的属性的信念）。
- **情绪由意义决定，不由属性本身决定**（P40-12）。「拥有某属性」这一事实对人物的意义，取决于该属性与各指导物的关系——**不要从属性直接跳到情绪**。
- **反馈回路方向要标对**（P19-06）：情绪会**反向**调用更严苛的评价标准，方向与 belief → appraisal 相反。这是一个环路，不是单向链。
- **与 SK-22 的边界**：若情绪可由「事件 × 目标」解释 → 走 SK-22；只有在情绪源于**自我表征与标准的落差**时才走本技能。
