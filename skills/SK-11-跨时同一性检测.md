# SK-11 跨时同一性检测（F3）

## 何时用

S3。图的节点**跨时间有取值变化**时。

## 输入 / 输出

- **输入**：含时间分层的图。
- **输出**：违例 `{节点, F3, 时间点, 无解释}`。

## 操作

1. **前置过滤（硬约束）**：剔除所有引用 **T > T\*** 的节点。
   - T\* 是当前叙事的「现在」。生成侧的正向约束是 **过滤 EMG by T ≤ T\***。
2. **识别变化**：同一节点在不同时间点取值不同。
3. **区分变化类型**（关键一步）：

| 类型 | 判据 | 是否 F3 |
|---|---|---|
| **随机变异** | 自相关 ≈ 0；**连续差分的均方是方差的二倍** | **否** |
| **模式化变异** | 单调增长、二次增长、昼夜循环等 | 是（需检查解释） |
| **时间依赖过程** | 行为之间存在**条件依赖**（喝咖啡→随后排尿，而非睡觉→困倦） | 是（需检查解释） |

4. **查解释边**：变化处是否存在显式或隐式的解释（事件、情境、成长、觉悟）。
   - 有解释 → 不是 F3。
   - **无解释** → **F3**。

## 边界与失效条件

- **违例 ≠ 错误**。P47-04 的完整要求是「**保持相同 或 给出解释**」。检查器输出的是「**违例 + 待解释**」——是**请求解释**，不是判错。
- **不要把随机波动报成 F3**。角色情绪的自然波动不构成跨时不一致（P45-03／04）。误把随机变异当问题，会产生大量假阳性——**这是本技能最主要的失效方式**。
- **不要把「成长」当成不一致**。P12b-13：「**人格发展并不遵循离散的锁步阶段，但确实表现出足够的结构与方向，使发展里程碑可被识别以标记渐进的变化与连续**」——**变化本身是正常的**，问题只在于**有没有解释**。
- **⚠️ 自相关判据对单个角色不可直接计算**。P45-03 的「连续差分均方＝方差二倍／自相关」是在**四类假想过程**上做的论证示例，需要足够多的等距时点。单个角色在文本中通常只有少数几个时点。**操作降级**：退化为定性判断——**同一取值是否反复出现且无明显趋势**（→ 视作随机波动） vs **取值是否单调／二次／周期性地移动**（→ 视作模式化变异）。**不要输出一个算不出来的数。**
- **T\* 过滤是硬约束**：任何引用未来事件的节点都不得进入图。这不是「不一致」，是**建图前置拦截**（见 SOP.md §4.3）。
- **隐式解释也算**。不必有明文说明；文本上下文足以推断即可。判断标准是「读者能否不违和地接受这个变化」。

- ⚠️ **P47-04 不是 F3**（dry run 发现）。**P47-04** 讲的是**叙事话语的约束**——作者必须让读者接受「是同一个实体」，违例须有**显式或隐式的解释**。**F3** 讲的是**本 SOP 的跨时检查**——断言的 if-then 剖面跨时间是否稳定。**两者不可互相引用为证据。** 判据：若从未检出跨时取值变化，理由是「无变化可检」，**不是**「P47-04 已满足」。
- ⚠️ **无属性断言时 F3 无对象**。D2（Peter 三句）**未给出任何属性断言**——三句都只索引「存在性」。此时 F3 **不适用**，不得为了产出判定而虚构属性。
- ⚠️ **材料例句 ≠ 材料主张**（dry run 发现的误用）。P24-12 用 Rick 那组例句证明的是「四视点」与「陈述交织」，例句被引号标出**作为举例**。**把它当跨时变化送进 F3，等于替作者改了他句子的用途。** 引用材料例句前先问：**该句在原文里是主张，还是例证？**
