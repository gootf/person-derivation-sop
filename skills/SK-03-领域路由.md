# SK-03 领域路由

## 何时用

S1 收尾，**每条断言入库前**。

## 输入 / 输出

- **输入**：断言。
- **输出**：带格位的断言。

## 操作

判定该断言落入哪一格：

|  | **稳定特质** | **短暂状态** |
|---|---|---|
| **身体** | **A1** 身体倾向（物种、体格、年龄、性别、位置） | **B1** 暂时身体状态（外部行动、空间移动、疾病、衣着、面部表情） |
| **心理** | **A2** 心理倾向（**人格、自我概念**） | **B2** 心理**过程**（感觉、思想、情感）与**瞬时状态**（计划、注意力不集中） |
| **社会** | **A3** 社会结构中的位置与关系（角色、群体归属、关系、职业、地位） | **B3** 社会行为（互动、冲突、沟通） |

## 依据

| rule_id | 强度 | 原文要点 |
|---|---|---|
| P24-04 | necessary | 上表即 Table 6 的六格枚举 |
| P24-01 | necessary | 角色模型「是关于一个被表征存在之特质的心智表征系统」，「特质」**广义上**指所有类型的身体、心理、社会与行为相关属性，**无论恒定或可变** |

## 依据分级

| 级 | 内容 |
|---|---|
| **【提取】** | P24-04 六格枚举（A1/A2/A3 × B1/B2/B3）；P24-01 特质广义定义（含恒定与可变） |
| **【设计决定】** | **「推导链落在 B2」「A2 是输入而非目标」「A1/A3 是并行状态」是本研究的问题定位分配**——材料只给六格分类，未规定哪一格是推导作业面 |
| **【自建】** | 无 |

## 边界与失效条件（关键）

- **推导链落在 B2**（心理过程与瞬时状态）。这是本 SOP 的作业面。
- **A2 是输入**，不是输出——「已确立属性」通常是 A2。**不要把 A2 当作推导目标。**
- **A1／A3 是并行状态**，不是人格。**不可塞进同一人格向量。**
- **B2 内部再分「过程」（感觉／思想／情感）与「状态」（计划／注意力）**——故评价（**P19 系列**）与意向（**P42 系列**）**不可合并**。
- 格位判断错误会污染整条下游：把 A3 当 A2 会把「社会位置」误当「人格特质」推导。
