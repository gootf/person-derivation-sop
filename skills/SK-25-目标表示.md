# SK-25 目标表示

## 何时用

S4。激活扩散命中了某个目标类节点，需要把它**写成一个可参与推理的结构**时。

## 输入 / 输出

- **输入**：目标类断言。
- **输出**：目标记录（四层描述 + 五项属性）。

## 操作

### 一、按四层描述目标（不要压平）

| 层 | 内容 |
|---|---|
| **properties** | 目标类的**共同属性** |
| **dimensions** | 目标在其上变化的**构念** |
| **content** | **具体内容** |
| **structure** | **相互关系** |

**结构不等于刚性；内容与维度取值均可变。**

### 二、关系的默认形态：层级

多目标间的关系**以层级结构为主导概念化**。

### 三、按五属性登记每个目标

| 属性 | 含义 |
|---|---|
| **名称** | |
| **数值** | 表示该目标的重要度 |
| **所需规范** | 达成该目标的前置条件之一 |
| **所需人格特质** | 前置条件之二 |
| **所需信念** | 前置条件之三 |

**一个目标能否达成，取决于这三类前置条件是否齐备。**

### 四、排除假目标

**呈现 equifinality 或稳态，不蕴含「有目标」**——目标性**需要额外判据**。

| 级 | 内容 |
|---|---|

| **【设计决定】** | 把「四层 → 层级 → 五属性 → 排除假目标」组织为**四步操作顺序** |

## 边界与失效条件

- ⚠️ **P30-05 原文说「目标有四个属性」，但随后列举了五项**（名称、数值、所需规范、所需人格特质、所需信念）。**这是原文自身的计数不一致**，本技能按实际列举的五项登记，并在此登记该差异。不要自行删去一项以凑数。
- **结构不等于刚性**（P35-01）。目标的内容与维度取值**均可变**——不要把目标当成固定枚举。
- **equifinality 或稳态不是目标的证据**（P35-03）。一个系统表现出「殊途同归」或「回到稳态」**不足以**断定它有目标；须另找目标性判据。
- **目标与信念、标准不可互换**（P19-16 及 P19-01）：目标**不客观为真或为假**。若一条断言可以为真为假，它不是目标。
- **达成与否看三类前置条件**（P30-05）：规范、人格特质、信念。**缺任何一类，该目标在给定人物身上不成立**——这是本系统判定「某目标是否可能属于该人物」的依据。
- **规范生命周期有别于目标**（P30-12）：规范有四步（采纳／审慎／遵守 + 冲突核实），**不要把它与目标的五属性混成一张表**。
