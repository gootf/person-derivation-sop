# SK-21 评价维度与序列

## 何时用

S4 状态推导的**第一步**。情境线索已激活相关节点后，判定人物对该情境形成了**哪些评价**。

评价是情绪的上游：**评价过程的性质决定情绪过程其余各阶段的性质**。

## 输入 / 输出

- **输入**：情境 + 人物的目标、信念（来自 R4 技能组）。
- **输出**：该事件的**评价向量**（各维度取值）。

## 操作

### 一、逐维度判定

| 维度 | 判据 |
|---|---|
| **新颖性 / 预期性** | 事件是新的或出乎意料的吗 |
| **目标相关性** | 事件与人物目标相关吗 |
| **效价（两类，必须分开）** | **内在效价**（愉快与否）／**目标一致性效价** |
| **能动性与有意图性** | 事件由谁造成、是否有意 |
| **控制** | 前瞻控制：威胁评价 ↔ 低控制；挑战评价 ↔ 高控制 |

### 二、按序列使用（不要并行处理）

评价**有先后**，且证据是毫秒级的：

| 顺序 | 评价 | 证据 |
|---|---|---|
| 1 | 新颖性 | 新颖性效应**先于**内在效价效应 |
| 2 | 目标一致性 | 反馈开始后**约 600 毫秒**出现主效应 |
| 3 | 前瞻控制 | **约 800 毫秒**出现主效应；**控制高时目标一致性的效应被放大**，控制低时不变 |

### 三、记住过程是递归的

情绪过程**假定高递归性**：初始因果效应从左向右推进，但一个成分对另一成分作用的结果**会反馈回引发成分**，启动新一轮处理并可能改变最终结果。**因此大多数箭头是双向的。**

### 四、情绪过程分四个功能阶段

| 阶段 | 内容 |
|---|---|
| (a) **生成** | 对事件的评价生成情绪情势 |
| (b) **行动准备** | 行动准备状态与生理反应 |
| (c) **信息整合** | 两步整合为中央表征以监控调节 |
| (d) **范畴化与传达** | 对情绪情势做范畴化并向他人传达 |

**标签化是第四阶段，独立于生成。** 不要因为某情绪没被命名就认为它没有被生成。

## 边界与失效条件

- **两类效价不可当独立可测的量**。P04-02 明写两者「**实证上难以解离**」。若把它们当正交维度分别打分，等于假设了一个材料明确说难以成立的结构。
- **不要只用一个效价维度**。P04-21／P04-34 显示两类效价的**输出通道不同**：内在效价对面部肌电的影响更稳健，而**只有目标一致性**显著影响平均皮电、额头温度与手指温度；声学上频谱能量分布取决于内在效价，音高动态取决于两者的交互。**用一个维度会丢掉另一条通道的信息。**
- **序列只对「组合」成立，不能反推**。毫秒级证据说的是**同时呈现时的先后**，不是「某个评价不需要前面的步骤」。**不要据此断言某评价可以跳过上游。**
- **不要从情绪词反推评价**。第四阶段（范畴化）**独立于生成**——人物可以说出「我很愤怒」而实际评价结构并非愤怒；P04-06 的混合情绪数据（同一情势 42.8% 报愤怒、38.3% 报悲伤、23.8% 报轻蔑，**多人同时报多个**）表明标签与情势不是一一对应。
- **目标不一致性优先于公平性**（P04-16 的实测结果）。当两者同时可用时，按前者判。
- **评价维度不是全部内容**。P04-11 明确指出作者**只处理了四条路径中的两条**（评价→行动倾向、评价→生理反应、评价→动作表达，实际讨论范围有限）——不要把这个维度集合当作评价的完备理论。

## 自检

- [ ] 两类效价是否分开判定了？
- [ ] 是否按新颖性 → 目标一致性 → 前瞻控制的顺序处理？
- [ ] 有没有把人物**说出的**情绪词当作评价结构？
- [ ] 递归性是否考虑了（某成分的结果会不会反馈回引发成分）？
- [ ] 目标不一致性与公平性同时可用时，是否按前者优先？
