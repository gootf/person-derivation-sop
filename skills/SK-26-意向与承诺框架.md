# SK-26 意向与承诺框架

## 何时用

S4。目标已登记，需要把「**该人物打算为此做什么**」写成结构时。

## 输入 / 输出

- **输入**：目标记录 + 计划结构。
- **输出**：意向记录（潜在意向命题 ＋ 承诺框架）。

## 操作

### 一、意向分两处记录（缺一不可）

| 位置 | 形态 | 记录什么 | **不**记录什么 |
|---|---|---|---|
| **世界状态中的潜在意向** | 命题 `intends(a, ga)` | 角色**可以有一种意向** | **不表示该意向是否被付诸行动**，也不捕捉角色为行动执行哪些后续步骤 |
| **承诺框架** | 数据结构 | 进一步**细化该意向**，识别角色为追求该意向**将执行哪些行动** | |

### 二、承诺框架是五元组

**⟨S′, P, a, ga, sf⟩**

| 元件 | 含义 |
|---|---|
| **S′** | 计划 `P = ⟨S,B,O,L⟩` 中**步骤的真子集** |
| **a** | 一个**角色代理**的符号引用——该角色是 S′ 中**所有步骤的行动者** |
| **ga** | 角色 a 通过执行 S′ 中步骤所追求的**目标** |
| **sf** | **最终步骤**——以 ga 为其效果之一，且 S′ 中**其他所有步骤在计划 P 的步骤序 O 中都时间上先于 sf** |

### 三、允许多个步骤共用一个目标

**一个意向性区间可以包含多个以 ga 为效果的步骤**——这在另一行动在世界中撤销了 ga、该条件必须被重建时是必要的。

### 四、所有角色行动都应是有意的

**对每个角色目标，完整 fabula 计划中都有一段行动是描述该角色为达成该目标将执行的行动。**

### 五、意向的发现是机会性的

意向发现**以扩散激活的方式运作**：当一个步骤成为某个承诺框架的成员时，**一整串建立步骤可能随之而来**。

**原因**：承诺框架可以在计划精化的任何时刻被创建。

## 边界与失效条件

- ⚠️ **两处记录不可互相替代**（P42-04）。**`intends(a, ga)` 命题不表示意向是否被付诸行动**——只有承诺框架才识别「将执行哪些行动」。**只用命题记录会把「想过」和「要做」混为一谈。**
- ⚠️ **意向可以在计划过程中才出现，也可以只是反应**（P42-10／11）。**不要假定所有意向都在初始状态里给全**；也要允许人物「只是对世界状况或他人行动作出反应」而形成意向。
- **机会性发现代价高**（P42-09）：「在行动实例化时机会性地发现角色意向**显著增加分支因子，损害生成长叙事的能力**」。本技能在**推理**方向可用，在**生成**方向有已知成本。
- **五元组的 sf 有强约束**：sf 须以 ga 为效果之一，且 S′ 中**其他所有步骤都时间上先于它**。**不要按「最后一个写的步骤」当 sf。**
- **可信性判据是「被感知为意向性行动者」**（P42-01）——是**读者侧**判据，不是「人物确实有完整计划」。
- **不要用「自然／可信」当规划约束**（P42-02 的否定）：原文明确其规划器「**不考虑角色在计划中任一时刻执行某行动是否自然或可信**」，作者自己也论证这**限制了适用性**。若要做可信性判断，走 P42-13 的观众视角，而不是给规划器加一条「自然性」判据。

## 自检

- [ ] 意向是否**两处都记了**（命题 + 承诺框架）？
- [ ] 五元组是否五个元件齐全？
- [ ] sf 是否满足两条约束（以 ga 为效果、时间上最后）？
- [ ] 有没有把 `intends` 命题当成「已决定行动」？
- [ ] 意向是否允许了「过程中发展出」与「纯反应式形成」两种来源？
