# SK-10 符号冲突检测（F2）

## 何时用

S3。对每条有入边的断言，检查入边**符号**与断言方向是否相反。

## 输入 / 输出

- **输入**：图。
- **输出**：违例 `{断言, F2, 反向入边列表}`。

## 操作

1. 取断言 `X` 的入边集 `In(X)`。
2. 逐条看符号 σ：`+` 支持 X 的方向，`−` 相反。
3. 存在 σ = `−` 的边 → **F2 符号相反**：文本给出的成因推出与断言相反的结论。
4. 记录这些反向入边及其权、折扣状态（供 SK-16 用）。

## 依据

| rule_id | 强度 | 原文要点 |
|---|---|---|
| P01-04 | strong | 仅凭「单元间连接**强度与符号**的个体差异」，就能产生稳定的平均水平差异——**符号是结构量，不是解释** |
| P24-02 | necessary | 角色模型「**不是一袋松散属性，而是一个动态系统；它们在一个因果联系或联想推断的网络中被链接**」 |

## 例

「家庭里父母比较强势」＋「本人强势」

→ 若文本把「父母强势」建立为对本人强势倾向的**负向**入边（强势的父母压制了本人强势的形成），而断言说「本人强势」→ **F2**。

## 依据分级

| 级 | 内容 |
|---|---|
| **【提取】** | P01-04 连接有强度与**符号**、且符号存在个体差异；P24-02 角色模型是因果／联想网络而非属性袋 |
| **【设计决定】** | **F2 的图论表述**；**「检出 F2 ≠ 判冲突」**（分界交 SK-16）；「符号必须是文本建立的」这一门槛 |
| **【自建】** | 无 |

## 边界与失效条件

- **符号必须是文本建立的，不能是读者先验**。若「父母强势 → 本人不强势」只是读者的常识期待、文本并未建立这条关系 → **走 S6 预期落差，不走本技能**。
- **检出 F2 ≠ 判「冲突」**。F2 是**结构事实**（存在反向入边）；最终落「冲突」还是「信息不足」由 **SK-16** 按该反向入边的**权**与**折扣状态**决定。**证据不足与证据相反是两件事。**
- **符号的建立需要可指认的关系句**。若文本只是并置了两个属性、没有建立关系，则它们之间**没有边**（连弱边都没有），既不是 F2 也不是张力。
- **不要用「负面属性」当负号**。符号是**关系**的方向，不是属性的效价。「父母强势」与「本人强势」都是「强势」，符号看的是前者对后者的作用方向。

## 自检

- [ ] 这条反向关系在文本中可指认吗？还是我根据常识补的？
- [ ] 是否把「属性效价为负」误当成「符号为负」？
- [ ] 反向入边的权与折扣状态是否记录了（供 SK-16 判定）？
