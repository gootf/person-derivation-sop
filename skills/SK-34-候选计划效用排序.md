# SK-34 候选计划效用排序

## 何时用

S4。**候选计划集已给出，需要排序时。**

**这是 SK-15「在候选集内排序」的一种具体算法**（是 refinement，不是其前置）——SK-15 规定了「只在候选集内排序」，本技能给出**怎么排**。

## 输入 / 输出

- **输入**：候选 agent plan 集 ＋ 人格因子得分。
- **输出**：计划排序（按效用）。

## 操作

### 一、五步链路

```
12 个已有规划特征
   → 5 因子得分加权求和
   → 5×1 向量
   → 效用 = 欧氏范数
   → 排序
```

**人格的作用点**：**人格 = 在候选 agent plan 之间做选择**。

### 二、效用计算六步（每因子内特征等权）

**因子内部的特征等权**——不要给同一因子下的特征设不同权重。

### 三、零分的特殊处理

| 情形 | 处理 |
|---|---|
| 某因子分为 **0** | **不忽略其特征**，而是取「**趋近平均**」 |
| 特征值公式 | **`特征值 = −0.1 × |该值 − 平均值|`** |

**后果**：**中等人格表现为选最接近平均的计划。**

### 四、留意图纸上的负相关标记

**部分特征与对应面向负相关**——即某特征值高，对应的因子得分反而低。

## 边界与失效条件

- ⚠️ **特征清单与系数未给**。材料只说「12 个已有规划特征」「5 因子得分加权求和」，**没有列出这 12 个特征是什么，也没有给加权系数**。**本技能给出的是算法形状，不是可跑的算法。**
- ⚠️ **实证支持弱**（P15-04）：三条假设中**只有前两条得到支持**，第三条（同时匹配量表标记与后续故事）**仅 1/5 因子显著**，且「**效应量普遍偏低**」。**不要把本算法的输出当作高置信度预测。**
- ⚠️ **负相关的存在意味着不能假定「特征越高 → 因子越高」**（P15-01 原文：「**部分特征与对应面向负相关**」）。**逐特征核对方向，不要按名字猜。**
- **零分不是「无影响」**（P15-03）——这是本算法最容易搞错的一点。因子分为 0 时**特征仍参与计算**，取趋近平均。**若跳过零分因子，中等人格的人物会得到完全不同的排序。**
- **欧氏范数是排序量，不是概率**。它给的是**序**，**不要把它归一化成概率输出**（本项目没有把效用转概率的依据；softmax 的 `b` 参数见 SK-35，那是另一条路径）。
- **候选集仍须由输入给出**（SK-15 边界）。**本技能不生成候选计划。**
