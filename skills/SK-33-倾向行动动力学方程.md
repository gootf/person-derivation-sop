# SK-33 倾向行动动力学方程

## 何时用

S4。**这是全工作区唯一一处有完整可编码方程的地方**——其余各环给的都是定性判据或方向。

适用条件：**需要「随时间推进」地推导倾向与行动**，而不只是静态判定。

## 输入 / 输出

- **输入**：三个向量——**环境线索 `c`**、**潜在倾向 `t`**、**可观察行动 `a`**。
- **输出**：两个变化率——**`dt`（倾向的变化率）**、**`da`（行动的变化率）**。

## 操作

### 一、两个方程

```
dt = Sc − Ca        （1）
da = Et − Ia        （2）
```

> **OCR 说明**：台账该条的 PDF 抽取结果为 `dt ¼ Sc−Ca` / `da ¼ Et−Ia`——**`¼` 是 `=` 的 OCR 伪影**。此处按数学含义写作 `=`。**引用原文时须保留该伪影并加注**，不得静默改写。

### 二、四类个体差异用矩阵表示

**人格的个体差异被表示为矩阵 `S`、`C`、`E`、`I` 的取值**，它们**影响三个向量之间的联结**：

| 矩阵 | 含义 |
|---|---|
| **`S`** | **线索敏感性**——环境线索对倾向的作用 |
| **`E`** | **倾向与行动之间的激发强度** |
| **`C`** | **行动降低行动倾向的满足联结** |
| **`I`** | 行动自身的衰减／阻抗项（见边界：原文未给它的说明） |

### 三、读出稳定性含义

**持续吸引子**：**特质等价于控制论系统的持续吸引子状态**——它们**指示该人会趋向的状态，但并不排除该人处于其他状态**。

## 边界与失效条件

- ⚠️ **原文计数不一致**：P45-06 说「**四类**个体差异被假设存在」，随后**只列举了三项**（线索敏感性 S、激发强度 E、满足联结 C），而矩阵处列出**四项**（S、C、E、I）。**`I` 的含义在该条中未给出。** 本技能按四项矩阵使用，并在此登记该差异；**不得自行推断 `I` 的语义。**
- ⚠️ **取值全部未给**。方程是**形式**，不是**数值模型**。**在标定之前，本技能只能做定性推理**（例如「提高线索敏感性 S 会使倾向更强烈地响应环境」），**不能算数。**
- ⚠️ **OCR 伪影必须在引用时保留**。原文抽取为 `¼`，按 `=` 理解；**引用原文时不得静默改写**——须保留 `¼` 并加注，否则会掩盖一次抽取缺陷。
- **这是「简单控制论模型」**（原文自述）。**不要把它当作完整人格模型**——它只连了三个向量，不含目标、信念、评价。
- **吸引子不等于确定性**（P45-07）：「**并不排除该人处于其他状态**」。**特质指示趋向，不锁定状态**——不要用它占卜单次行为。
- **动态性有硬判据**（P45-01）：「要被称为动态的，**过程必须依赖于时间**」。**不要因为模型里有「状态」二字就称其动态**——CAPS 与 KAPA 都被判定为形式上不是动态模型。
- **特质读作变化率，不是概率**（P45-04）：「把特质看作**状态的变化率**比看作**处于某状态的可能性**更有用」。**这与把人格当作概率分布的做法方向不同。**
