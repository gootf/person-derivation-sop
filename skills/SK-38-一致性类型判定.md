# SK-38 一致性类型判定

## 何时用

**S3 良构检查之前、每次一致性检查之前。** 本技能是**一致性检查的前置声明**。

**它是一条闸门**：未声明检查的是哪一类一致性，**不得进入 SK-10／SK-11**。

## 输入 / 输出

- **输入**：待检查的断言集。
- **输出**：**本次检查的一致性类型声明**（五选一或多选，须逐项列出）。

## 操作

### 一、声明是哪一类（五类彼此独立）

**「一致性」不是单一标量。必须先声明是哪一种。**

| 序 | 类型 | 由什么支撑 |
|---|---|---|
| **①** | 信念一致性 | **beliefs** |
| **②** | 目标一致性 | **goals** |
| **③** | 评价标准一致性 | **evaluative standards** |
| **④** | 跨系统功能互作一致性 | 跨系统的**功能互作** |
| **⑤** | 现象学一致性 | **现象学层面** |

**五类彼此独立**——各自由不同机制支撑，**不存在「总体一致性」**。

### 二、按机制分两组，而不是按现象分

| 组 | 包含 | 范围 |
|---|---|---|
| **跨情境组** | ①②③ | 处理**跨情境一致性** |
| **系统内与现象组** | ④⑤ | 分别处理**系统内互作**与**现象学一致性** |

**路径的划分依据是「产生机制」，而非「现象类型」。** **不要按「看起来像哪一种不一致」来归类**——要看**背后是哪套机制在起作用**。

### 三、检查对象只能是结构

**必须区分「人格结构」（跨情境稳定）与「人格状态」（随情境变化）。一致性检查的对象只能是结构，不能是状态。**

**操作含义**：**把状态当作检查对象会系统性地误报。** 同一状态在不同情境下不同，**那是定义如此，不是不一致**。

### 四、判据是「变异模式的稳定性」，不是高一致性系数

**跨情境一致性存在理论上限；追求更高的跨情境一致性系数在方向上是错的，正确的判据是「行为变异模式的稳定性」。**

**操作含义**：**不要输出「一致性得分」并追求它变高。** 要检查的是**变异模式（if-then 剖面）本身跨时间是否稳定**。

### 五、区分行为一致性与倾向一致性

| 类型 | 定义 |
|---|---|
| **行为一致性** | **观察到的行为之间的协变** |
| **倾向一致性** | **行为趋势指标之间的协变** |

**两者不是一回事。** 前者在原始行为层，后者在聚合指标层。

### 六、判断「类型」时，shape 与 elevation 都要用

**观察者对人物类型的判断同时依赖剖面的 shape 与 elevation；改变变异模式就会改变人格判断。**

**操作含义**：**两条剖面「同一形状、整体高低不同」与「同一高低、形状不同」不是同一类型。**

## 边界与失效条件

- ⚠️ **不得跳过类型声明**（P03-01 原文：「**必须先声明是哪一种**」）。**输出「不一致」而不说哪一类，等于没做检查。**
- ⚠️ **不得追求高一致性系数**（P01-05）。原文判定这个方向「**在方向上是错的**」。**若工具的优化目标是让一致性分数变高，它与本 SOP 的方向相反。**
- ⚠️ **不得把状态当检查对象**（P01-07）。**这是最常见的误报来源**：某人在葬礼上沉默、在球场上活跃——**这不是不一致**，它是同一结构在不同情境下的状态表现。**只有当变异模式本身（if-then 剖面）跨时间改变时，才构成 SK-11 意义上的跨时问题。**
- ⚠️ **④⑤两类只能声明不能执行**。材料给出名称与支撑层，**未给判据**。**报告这两类时应写「已声明，无法判定」**，不得用①②③的做法套上去。
- **五类型不可加总**（P03-01：「**彼此独立**」）。**不要输出「一致性总分」。**
- **分类按机制，不按现象**（P03-02）。**同一表面现象可能来自不同机制**——先定机制，再定类型。
- **行为一致性 ≠ 倾向一致性**（P33-06）。两者在**不同聚合层**；**比较它们时须声明所比较的层。**
- **类型判断不能只看形状**（P01-09）。**elevation 也参与**——两条形状相同但整体水平不同的剖面会被判为不同类型。
- **倾向的类别边界是模糊的**（P33-02）：「**类别边界是模糊的**……**成员资格的原型性上有所不同**」。**不要把类别当离散箱子**——这条与 SK-01（断言化）的阈值问题同源。

- ⚠️ **一致性类型由被检查断言的认知内容决定，不是固定值**（dry run 发现）。**不得对所有断言写死同一类**——P03-01 要求声明的是「本次检查的类型」，它随被检查对象而变。
- ⚠️ **存在性陈述无对应类型，**不得硬塞进最近的一类。**如「存在一个名为彼得的叙事实体」——它不是心理内容，不属于①—⑤任何一类。** 此时应记「**一致性类型不适用**」并**说明理由**，而不是勉强归入「信念」或「目标」。**硬塞会污染该类型的判定**（例如把存在性塞进「目标一致性」，会让「他存在」被拿去查目标冲突）。

## 自检

- [ ] 是否**显式声明**了本次检查的是哪一类（或哪几类）一致性？
- [ ] 该类型是**按被检查断言推出的**，还是写死的？
- [ ] 若是存在性／非心理内容，是否记「不适用」而非硬塞？
- [ ] 分类依据是**机制**还是现象？
- [ ] 检查对象是**结构**还是状态？（必须是结构）
- [ ] 是否避免了把「一致性系数变高」当目标？
- [ ] 是否区分了**行为一致性**与**倾向一致性**（并在比较时声明所比较的层）？
- [ ] 涉及④⑤时，是否写了「已声明、无法判定」而非硬做？
- [ ] 若做了类型判断，是否同时用了 shape 与 elevation？
