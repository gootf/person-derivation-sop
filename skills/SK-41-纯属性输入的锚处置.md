# SK-41 纯属性输入的锚处置

## 何时用

S1。**当输入本身就是「已确立属性」——属性清单、三元组、trope 标签——而完全没有过程陈述时。**

**这不是边缘情况，而是本 SOP 必须支持的核心输入形态。** SK-01 第 4 步会把这类片段判为「不含过程陈述 → 报 S8」，而 S8 是请求补充描述的死路——**若不处置，最典型的输入会在第一步被赶出去。**

## 输入 / 输出

- **输入**：属性清单／三元组／标签集，**无过程陈述**。
- **输出**：**三档处置之一**（见下），**不得默认走 S8**。

## 操作

### 一、先分清「谁在断言」

| 情形 | 断言的来源 | 处置 |
|---|---|---|
| **文本内给出** | 文本自己写了角色「害羞」 | **档 A：文本内断言**，锚 = 该属性陈述本身 |
| **外部给出** | 归因者／设定者告知「他害羞」 | **档 B：外部给定属性**，锚 = **外部来源**，标记 `anchor=external` |
| **先验推断** | 由领域常识／ trope 推出 | **档 C：先验侧**，转 S6 落差对照，**不建入边** |

### 二、档 A：文本内断言（可直接建图）

若「害羞」是**文本自己写出的角色属性**，它就是文本内证据。

**但注意 P28-03 的限定**：「**形容词描述过于笼统，且只适用于故事中有限的语境**」——故它**可建入边，但权不能高**，且须标 `source=文本内形容词`。

### 三、档 B：外部给定属性（`anchor=external`）

**这是用户输入的主情形。** 「已确立属性」由输入方给出，**它不是文本内证据**。

**必须做的三件事**：

1. 标 `anchor=external`——**否则它会与文本内断言混同，在 F1 悬空检查里被当成「文本没给出成因」而误报**。
2. **不得计入 F1 的入边集**——外部属性没有文本内发展结构，按 P46-05 它至多是**维度**，不是功能。
3. **它同时是 S6 落差对照的输入**——先验侧与文本侧之差正是落差（P24-06）。

### 四、档 C：先验推断（转 S6，不建入边）

由 trope／领域常识推出的属性**属于先验图**，不是文本图。**建入主图会污染一致性检查**——那会让「符合刻板印象」被报成「有文本依据」。

### 五、歧义时的默认

**若输入无法判定属于档 A/B/C**：按**档 B（外部）**处理并明确标记。**理由**：把外部属性误当文本内证据的风险（污染 F1、虚高入边强度）**大于**把文本内属性误当外部属性的风险（少建一条边，可由 S8 补）。

| rule_id | 强度 | 原文要点 |

| P47-05 | necessary | 「**而实体要么是角色，要么是环境要素——这个区分基于它是否执行情节上显著的行为。**一个静止陈述可以传达**实体的同一性或其某一方面的一个性质**，例如特质（见第 3 章）。」 |
| P46-05 | necessary | 「**维度是角色在脱离其所处的作品时被认为可能具备的任何属性。功能是文本通过其发展结构对该属性所作的特定应用。**……**每个功能都依赖某个维度，但不是每个维度都必然对应于某个功能。**」 |

| P24-06 | necessary | 「**这些倾向常常促使人超出影片明确提供的信息，为角色推定更广泛的特质星座或某些联想。**」 |
| P46-03 | necessary | 「**卡勒关于角色是一组谓词的概念并不超出解释**——这些谓词（或品质）有时**必须从看到某个专名与言语、思考或行动的关联中推断出来**，甚至要从看到某个专名与另一个专名的言语关联中推断出来。」 |

| **【自建】** | ⚠️ **档 A 的权上限**——P28-03 只说形容词「过于笼统」，**未给「不能高」的具体界** |

## 边界与失效条件

- ⚠️ **P47-06 不支持档 B**。它是「**有**过程陈述 ⇒ **有**断言」的单向蕴含。**拿它给纯属性输入背书是读反了材料。** 本技能为档 B 提供的依据是 **P46-05（维度不必然对应功能）＋ P28-03（形容词笼统）**，**不是** P47-06。
- ⚠️ **档 B 属性不得计入 F1 入边集**（这是本技能最要紧的一条）。若把它算进去，F1 悬空检测会判「文本没给出成因」——**而真相是成因在文本外**。**这会把一个输入格式问题报成人物缺陷。**
- ⚠️ **外部属性与先验属性不可合并**。档 B 是**给定者说的**，档 C 是**领域推的**。**先验在文本外但可被 S6 对照；外部给定不构成落差基准**——**它就是基准**。混同会让落差侧失去参照。
- ⚠️ **形容词输入的信息量确实低**（P28-03）。**不要因为「它被明确写下来了」就给它高权**——P28-03 明确说这类描述**过于笼统且只适用于有限语境**。**明确 ≠ 可靠。**
- **档 C 不建入主图**。先验属性属 S6 对照侧；**建进主图会让「符合刻板印象」冒充「有文本依据」**。
- **trope 判定需要长上下文**（P28-04）。**不得用局部片段判定某个 trope 是否成立**——材料明说需要更长上下文。
- **不违反 SK-01 的第 4 步精神**。SK-01 那条规则针对的是「片段内含过程陈述但抽不出描述」的情形；**纯属性输入是另一种情况**——它根本不含过程陈述，**不是抽不出，是不需要抽**。**但须显式走本技能，不能默默跳过 SK-01。**

## 自检

- [ ] 输入是否含过程陈述？若否，是否**显式走了本技能**（而非默默按 SK-01 报 S8）？
- [ ] 每条属性是否判定了档 A／B／C 并标了 `anchor`？
- [ ] 档 B 的断言是否**已排除出 F1 入边集**？
- [ ] 档 C 的断言是否**未建入主图**、只作 S6 对照？
- [ ] 形容词类属性是否给了**受限的权**（P28-03）？
- [ ] 有没有拿 P47-06 给档 B 背书？（**不应如此**——它是单向的）
- [ ] 判为歧义时，是否按档 B 处理并说明理由？

## 附：与 SK-01 的分工

> **执行位置的准确表述**：SK-01 与 SK-41 **都在 S1 内**，由「有无过程陈述」这一判断**互斥分派**。依赖图上 `SK-01 → SK-41` 表达的是**判定顺序**（先看有没有过程陈述，没有才走 SK-41），**不是两个串联的转换步骤**。本技能 `depends_on: [SK-24]` 指的是它**产出**的断言需要 SK-24 判认知内容类型——**这是产出侧依赖，不是执行侧前置**。

| | SK-01 | SK-41 |
|---|---|---|
| **适用** | 片段**含**过程陈述 | 片段**不含**过程陈述 |
| **动作** | 抽出被索引的最低限度描述 | 判档 A／B／C，定锚的来源 |
| **失败出口** | S8 | **不失败**——三档都有处置 |

**顺序**：S1 先判「有无过程陈述」→ 有则 SK-01，无则 SK-41。**两者不是串联的两步，是互斥的两条入口。**
