# SK-20 输出契约

## 何时用

S7。产出最终结果。

## 输入 / 输出

- **输入**：判定集（SK-16）＋ 强度（SK-17）＋ 落差项（SK-18／19）。
- **输出**：最终报告——每条判定一个四元组，另附两个独立字段。

## 操作

1. **逐条写四元组**（见下）。缺任一字段则该条**不得输出**。
2. **把含糊度与落差作为独立字段附加**，不并入四元组。
3. **核对用词**（见「用词纪律」）。
4. **登记限制**：数据缺陷（P29-04）、权重未标定（SOP.md §5.1）、本系统非动态模型（P45-01）须随报告声明。

## 输出格式

每条判定为一个**四元组**：

| 字段 | 内容 |
|---|---|
| `断言` | 被判定的人物陈述 |
| `判定` | 冲突／信息不足／无冲突 |
| `强度` | 必然／高度倾向／情境依赖／仅可能／与既有模型冲突 |
| `依据` | 触发的 `rule_id` 列表 + **图上的路径** |

**另附两个独立字段**：

- `含糊度`（SK-12）——独立分量
- `落差项 + 落差值 + 标注`（SK-18／19）——独立维度

## 用词纪律

「连贯」与「一致」是两个**并列的不同属性**，各有独立定义：

| 用词 | 定义（原文） | 依据 | 本 SOP 何处使用 |
|---|---|---|---|
| **连贯** | 「**连贯性是故事生成的基础方面，关乎故事各部分契合得多好，以形成一个一致且逻辑上合理的叙事**」 | P29-06 | **内部一致性**查的是连贯——各条断言之间是否契合 |
| **一致** | 「**叙事实体必须从一个事件到下一个事件保持相同**」 | P47-04 | **跨时同一性**（SK-11）查的是一致——同一实体跨时是否保持 |

**两项在角色模型的性质清单中被并列列举**（P24-08：「多多少少详细的、选择性的、多维的、聚焦的、**连贯的、一致的**、类型化的、复杂的……」）——**并列即不同**，混用会导致判定层混淆。

## 边界与失效条件

- **每条判定必须可回溯**。没有 `rule_id` 与路径的判定不得输出——这是本系统的全部价值所在。
- **不要输出强度以外的置信度数字**。五档是台账枚举；数值置信度**无依据**（权重函数尚未标定，见 SOP.md §5.1）。
- **三条数据缺陷须随输出登记**（P29-04）：所依赖的数据集存在长度、规模、语言覆盖方面的已知限制——使用具体数据集做验证时须一并声明。
- **成分发展程度须随输出声明**（P46-02）：模仿与主题成分**可以被发展得或多或少**——判定某角色时须声明该角色在哪个成分上发展充分，否则读者无从判断本判定的适用范围。
- **残缺断言须带受限标注输出**（E9 实跑逼出）。S8 补充的是**新描述**，不是修补**旧断言**——推进时可能仍有断言缺索引锚或缺 `rule_id`。这些断言：
  - **不阻断**输出（有完整断言即可推进，见 SOP.md §3.1）；
  - **必须显式列入受限清单**，**不得静默丢弃**（否则读者无从知道哪些结论建立在残缺证据上）；
  - **不得被当作已确立属性**呈现——须标「未确立／待补证据」。
- **回边终止时的输出是合法结果**。补充轮达上限（§5.4：3 轮）后输出「当前输入不足以判定」+ **缺什么清单**（每项含 *缺什么* 与 *该补什么*），**这不是失败**，也不是空泛的「信息不足」。
- **终止时不得输出任何三值判定**——证据不足时硬判比不判更坏。
- **不要声称「动态人格理论支撑」**。P45-01 已判定 CAPS 与 KAPA **在形式上不是动态模型**（「研究跨情境的变异并不等于研究动力学」）。本 SOP 是**结构判定系统**，不是动态模型。
