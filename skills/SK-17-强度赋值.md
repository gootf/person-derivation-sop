# SK-17 强度赋值

## 何时用

S5，判定完成后。

## 输入 / 输出

- **输入**：判定 + 图上路径。
- **输出**：带强度的判定。

## 操作

按五档赋值（**枚举沿用台账，不自行扩充**）：

| 强度 | 判据 |
|---|---|
| **必然** | 输入**直接蕴含**，或只经过 `necessary` 级规则 |
| **高度倾向** | 强证据支持，存在反例空间 |
| **情境依赖** | 条件成立时成立——**条件本身必须随输出一起给出** |
| **仅可能** | 弱证据，不可排除 |
| **与既有模型冲突** | 与台账内 `necessary` 规则方向相反 |

## 依据

台账 `derivation_strength` 枚举（necessary 361／strong 43／contextual 28／possible 1／conflict 5）。

## 依据分级

| 级 | 内容 |
|---|---|
| **【提取】** | 台账 `derivation_strength` 五档枚举（necessary 361／strong 43／contextual 28／possible 1／conflict 5） |
| **【设计决定】** | **五档 → 判据的映射表**（材料只给枚举名，未给上位判据）；「情境依赖必须附带条件」 |
| **【自建】** | 无 |

## 边界与失效条件

- **「情境依赖」的条件是机制的一部分**，必须随判定输出，不可省略。省略条件等于把情境依赖伪装成必然。
- **不要把「证据多」等同于「必然」**。必然来自**蕴含关系**（或纯 necessary 链条），不来自证据数量。
- **「与既有模型冲突」是与台账规则冲突**，不是与读者期待冲突。后者属预期落差（SK-19）。
- **强度由「属性 + 行为 + 情境」共同算出**，不是规则的静态属性——同一条规则在不同输入下可产出不同强度。

## 自检

- [ ] 「必然」的判据是蕴含，还是「我觉得很确定」？
- [ ] 「情境依赖」是否附带了条件？
- [ ] 有没有把「与读者期待冲突」误标成「与既有模型冲突」？
