# 人物推导 SOP —— 让「这个角色会不会做 X？」有证据可查

**[English](README.md) | 简体中文**

![License](https://img.shields.io/github/license/gootf/person-derivation-sop.svg)
![Release](https://img.shields.io/github/v/release/gootf/person-derivation-sop.svg)
![Stars](https://img.shields.io/github/stars/gootf/person-derivation-sop.svg)

**问一个 LLM「这个角色会不会做 X」，你会得到一段流畅的文字。它读起来像推理，但无法核验：没有引用、没有强度标注、明天再问同一句也无法对照。信息缺失时，答案不会变弱——只是把弱藏得更深。**

本仓库交付的是另一种工具：输入任意格式的人物材料——散文、特质清单、原型标签、片段——输出**一条可回溯的证据路径**，而不是一段看似合理的解释：

> **输入断言 → 机制规则（`rule_id`） → 图上路径 → 推导强度（五档） → 人物结论**

底座是 **438 条机制规则，全部绑定到可回溯证据**——每条带逐字原文摘录与五档推导强度，来自 44 篇全文核验文献（人格心理学与叙事规划并列）。

> **「不可判定」是合法答案。**
>
> 这套 SOP 不负责让答案更大胆，而是负责让不确定性显形：证据不够时，它停下来、列出缺什么、该补什么——而不是把猜测包装成结论。

## 没有它会怎样

| 故障 | 没有它 | 有它 |
|---|---|---|
| 特质被当成铁律——「内向者不去聚会」 | 一个标签，绝对行为 | 频率计量（SK-06）：特质-行为分布大量重叠，几乎没有行为为某特质独占 |
| 一个场景定性格 | 单观察归因 | 归因折扣阶梯（SK-07/SK-08）：一次行为能确立什么、不能确立什么 |
| 两个场景互相矛盾 | 被抹平成一个「连贯」的故事 | 矛盾是一等公民发现，按原样上报 |
| 信息不足 | 自信地猜 | S8 向输入侧索要补充——状态机唯一回边；判定标准从不为迁就数据而降低 |
| 「她不会那样做」 | 无从追溯的断言 | 判定 = `rule_id` + 图上路径 + 强度档位，逐步走回原文 |

## 30 秒：你会拿到什么

（示例按 SK-20 输出契约构造，展示输出形状；所引 `rule_id` 均真实存在于台账，可自行检索。）

```text
材料（散文，任意格式）：
  「她厌恶公开冲突，能躲就躲；但妹妹的安全是她唯一会当场翻脸的事。」
  「她惯于把立场藏在心里，除非有人逼她表态。」

问：她会在众人面前，当场质问一个正在威胁妹妹的人吗？
```

**结论（第一眼）：**

> **会——在给定条件下，公开对质有明确的机制支持；不能仅凭「厌恶公开冲突」排除它。**
> 触发条件：威胁指向妹妹、且发生在她在场时。推导强度：情境依赖（条件是机制的一部分，随结论一起输出）。

**展开审计视图（SK-20 四元组）：**

```text
  断言：她会在公开场合对质威胁妹妹的人
  判定：无冲突 —— 人格例外已注册，非模型矛盾
  依据：P18-01 人格例外＝（情境触发器＋人格修正效果）
        P18-02 触发显著度取自角色内部记忆，非外部情境类别
        P22-02 意向性是归因的调节因素
        图上路径：[厌恶公开冲突] ─σ−→ [公开对质] ←修正─ [例外：妹妹安全受威胁]
  另附独立字段：含糊度＝低；落差项＝「读者可能预期她始终回避冲突」（独立标注，不改判定）
```

**同一个问题，普通 LLM 的答案长这样：**

```text
「她性格内向、厌恶冲突，因此大概率不会公开质问……」

审计问题：「内向」从哪里来？「因此」依据什么机制？
          妹妹的安全为什么没有改变结论？置信度是多少？
          删掉一句输入，结论是否仍然一样？
```

本 SOP 的答案里，这些审计问题每一个都有落点：每个中间判断都带锚点、规则、路径与强度——**缺证据，不升级结论**。

若材料再少一句——比如通篇没提她妹妹——S8 触发，输出不是猜测：
「当前输入不足以判定」＋ 缺失清单（每项：缺什么 / 该补什么）。

## 这套 SOP 为谁而做

核心用户：**需要让 LLM 从人物材料中可靠推导角色行为的人**。以下场景共享同一需求：

| 你是谁 | 你的处境 | 它给你什么 |
|---|---|---|
| **小说作者 / 编辑** | 长篇稿件中保持人物一致 | 冲突检查读；矛盾以带证据的结构化发现浮出，而非「感觉不对」 |
| **LLM 人设 / 角色扮演构建者** | agent 漂移、串角色、崩人设 | 锚定断言纪律：无锚断言不得进图，污染无法传播 |
| **角色 AI 产品 / 叙事游戏团队** | 对错有可计量成本的场合（角色一致性 QC） | 可审计的判定输出：每条结论可走回证据，可复跑、可归档 |
| **叙事生成研究者** | 需要能引用出处的人物模型 | 438 条规则台账：逐字摘录、五档强度、44 篇全文核验书目 |
| **审计 AI 人物判定的人** | 「模型为什么这么说？」 | 每条判定可走回：结论 → 图上路径 → 规则 → 摘录 → 文献 |

## 为什么是这套 SOP（可验证，而非要求信任）

你不需要相信本页的任何话——仓库自带让你自己检查的机制：

1. **每条规则有出处。** 438 条规则全部带 `rule_id → 原文摘录 → 文献`；台账摘录逐字核验 438/438。
2. **每条推导有路径。** 结论 → 图上路径 → 规则 → 输入断言；没有 `rule_id` 与路径的判定不得输出（SK-20）。
3. **仓库自身也被测试，数字由台账实测。** 23 门验证套件一键复跑（当前基线 19 OK / 4 SKIP / 0 FAIL）；文档里每个统计数字由 `tools/ledger_numbers.py --check` 从台账重算——数字过期会让门 FAIL，而不是随仓发行。

## 它怎么工作

一张图，三种读——不是三条管线：

```text
任意格式输入
        │ S1 归一化
        ▼
索引锚定的断言集
        │ S2 建图
        ▼
一张带权有向符号图
        │
        ├── 可达性 ───▶ 补全          （还确立了什么？）
        ├── 激活传播 ─▶ 行为倾向      （她大概率会怎么做？）
        └── 良构检查 ─▶ 冲突检查      （各部分是否自洽？）
```

主流程 S0–S8：摄入 → 归一化 → 建图 → 良构检查 → 激活与状态推导 → 判定 → 预期落差 → 输出 → 信息不足（唯一回边 S8→S1：**向输入侧要信息，不降低判定标准**）。

链条在自动化诚实地止步的地方止步：

```text
机制规则 (rule_id) ──机器──▶ 行为倾向 ──人工──▶ 人物结论
```

机器负责把「哪些规则支持这个行为」算清楚；人负责决定这些规则是否足以支撑人物层面的结论。「不可判定」不只在输入不足时出现——它同时是这个系统拒绝把行为倾向伪装成人物结论的机制边界。本仓库不把这个缺口包装成自动化能力——这是产品边界，不是未完成的功能。

### 怎么用：对你的材料出判定

1. **读** `SOP.md` §2–§4：输入分类（叙事文本／纯属性／trope 先验）与建图规则。
2. **归一化**（S0–S3）：把你的材料转成索引锚定的断言集、建图——人工执行，形态参见 `tools/s1_formats.py` 的七种输入格式。
3. **机器部分**：可达性／激活传播／入度（SK-14 等技能给出参数依据；脚本示例见 `tools/dryrun_e2e.py`）。
4. **人工两跳**：规则 → 行为倾向、行为倾向 → 人物结论（§5.6.12h：不可自动化）。
5. **输出三值**：确认／排除／不可判定——「不可判定」是合法结论，不是失败。

## 它故意不做什么

- **不生成故事。** 生成器产出文本；本 SOP 产出**判定**。
- **不输出数值置信度。** 边权与三值阈值未标定（SOP §5.1），只有五档强度——任何「87% 确信」都是无依据的。
- **不自动化最后两跳。** 规则 → 行为倾向 → 人物结论由人裁决；本仓库不把这个缺口包装成自动化能力。
- **不把「不可判定」当失败重试到出结果为止。** 证据不足时硬判比不判更坏。

## 已知边界

- **过程类机制缺口**：3/438（语料冻结，见 SOP §5.6.12l）——过程内动态只能方向性预测。
- **技能 ↔ 台账语义一致性**：抽样 30/30 一致（95% 置信上界 ≈ 9.6%）；非全审。
- **引文保真**：77 行锚词机器全中；140 行中文译写抽样 10/10 忠实——其余译写行不可逐条机检。
- **权重未标定**：故输出只有五档强度、无数值置信度。
- **本系统是结构判定系统，不是动态人格模型**（P45-01）。
